# Student Query Management Database

A basic SQL and MySQL project created to manage student details, course enquiries, follow-up dates, and admission status.

## Project Features

- Stores student details
- Stores course information
- Tracks student enquiries
- Manages admission status
- Tracks follow-up dates
- Displays interested students
- Displays demo booked students
- Counts enquiries course-wise

## Technologies Used

- SQL
- MySQL
- VS Code
- Git
- GitHub

## Database Tables

### 1. courses

Stores course name, duration, and fees.

### 2. students

Stores student name, mobile number, email, city, and enquiry date.

### 3. enquiries

Stores student enquiry source, selected course, admission status, follow-up date, and remarks.
